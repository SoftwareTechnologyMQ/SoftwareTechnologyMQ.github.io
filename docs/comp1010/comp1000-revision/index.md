Revision of the core COMP1000 concepts that COMP1010 builds on. The examples are in Java.

1. [Variables and Operators]({{ site.baseurl }}/comp1010/comp1000-revision/variables-and-operators): why `double val = 17 / 5;` makes `val` equal to `3.0`, and why `int f = 10 / 5.0;` doesn't compile
2. [Conditions]({{ site.baseurl }}/comp1010/comp1000-revision/conditions): `if`, `if-else`, chains, and common mistakes
3. [Loops]({{ site.baseurl }}/comp1010/comp1000-revision/loops): `while` and `for` loops, tracing, and common loop patterns
4. [Functions]({{ site.baseurl }}/comp1010/comp1000-revision/functions): defining and calling functions, parameters, return values and scope
5. [Arrays]({{ site.baseurl }}/comp1010/comp1000-revision/arrays): creating, traversing and searching arrays, references, and arrays in functions

{: .keynote}
> One idea runs through all five pages: **assignment is a two-step operation.** First the right-hand side is evaluated to a value of some type. Then that value is copied into the left-hand side, if the types are compatible. Passing arguments to a function, returning a value, and copying an array variable all follow the same rule.

Each page ends with exercises. Try them before opening the solutions.
